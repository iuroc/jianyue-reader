书架网格排版对照

同一批书名、同样的三列网格，只改文字块的处理方式。红色虚线标出「作者行基线」的位置，用来观察三列是否对齐。

现状
随内容收缩
不固定高度。行高由最高的一格决定，短书名格子的作者行悬在半空。
问题：同一行里作者行的位置不一样，扫过去是 参差 的。
方案 ①
标题固定两行 · 作者贴底
标题盒恒定两行，作者永远贴格子底部。空隙落在书名下方，三列作者基线对齐。
代价：单行书名的格子中间有约一行（18px）的空白。主流做法
方案 ②
标题固定两行 · 垂直居中
空隙分到书名上下各半行，断裂感弱一些。
代价：书名的起始线参差，同一行里有的从第一行开始，有的从第二行开始。
方案 ③
网格不放作者
只留封面 + 固定两行书名。参差从根上消失，作者信息进详情页。
代价：丢掉「同一作者的书」这类浏览路径，但网格节奏最干净。最简约
