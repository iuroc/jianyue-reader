# Spec Delta

## Purpose

规定简阅的视觉与交互基底：配色、字号、间距、图标、页头、按压反馈与加载/空/错误三类状态，
让所有页面看起来出自同一只手。

## ADDED Requirements

### Requirement: 双主题由统一 token 提供

系统 SHALL 以「纸」与「夜」两套主题提供全部颜色，页面 MUST 通过 token 取色，MUST NOT 硬编码色值。
切换主题 SHALL 立即作用于当前可见页面与系统栏图标明暗。

#### Scenario: 在夜间主题下打开任一页面

- **WHEN** 用户把主题切到「夜」并进入任意页面
- **THEN** 页面底色、文字色、发丝线色全部取自夜间 token，状态栏图标为浅色

#### Scenario: 新增一处着色

- **WHEN** 工程师需要给某个视图上色
- **THEN** 从 token 表取角色名（如 ink-1 / hairline / accent），不写十六进制字面量

### Requirement: 字号与间距使用受限阶梯

系统 SHALL 只使用 `28 / 20 / 17 / 13` 四档页面级字号与 `400 / 500` 两档字重；
阅读器内部另有 `15 / 17 / 20` 三档正文字号。间距 MUST 为 8 或 4 的倍数。

#### Scenario: 需要强调一段文字

- **WHEN** 某个标题需要比同组文字更突出
- **THEN** 通过提一档字号或把字重从 400 提到 500 实现，不引入新的字号值

### Requirement: 线稿图标统一规格

所有图标 MUST 使用 24dp 绘制盒、1.5dp 线宽、圆头端点，MUST NOT 出现第二档线宽或填充图标；
唯一允许的填充是目录当前项的圆形标记。

#### Scenario: 新增一个图标

- **WHEN** 界面需要一个新图标
- **THEN** 以 24dp 盒、1.5dp 线宽绘制，与既有图标并排时视觉重量一致

### Requirement: 页头结构全局一致

除阅读页外，每个页面 MUST 使用同一个页头组件：高 56dp、返回按钮为 48×48dp 触摸区且图标 24dp 居中、
标题 17sp 左对齐、右侧动作区同为 48×48dp。

#### Scenario: 从列表页进入详情页

- **WHEN** 用户在任意页面之间跳转
- **THEN** 返回按钮的横向位置、与顶部的距离、图标大小在所有页面完全相同

### Requirement: 可按下控件必须有按压反馈

卡片、按钮、图标、列表行等可点控件 MUST 提供按下反馈；涟漪 MUST 被控件形状裁剪，
MUST NOT 扩散成超出边界的整圆。

#### Scenario: 按下三列书架中的一个格子

- **WHEN** 用户按住某个书格
- **THEN** 出现与格子矩形一致的涟漪，且涟漪不外溢到相邻格子

#### Scenario: 按下圆形图标按钮

- **WHEN** 用户按住页头的返回按钮
- **THEN** 涟漪是圆形，并被裁剪在 48dp 触摸区内

### Requirement: 加载、空、错误三态统一

系统 SHALL 提供骨架、扫动进度线、空态、错误态四种状态表现；MUST NOT 使用转圈式加载指示，
MUST NOT 用弹窗或 Toast 报告网络错误。

#### Scenario: 列表首次加载

- **WHEN** 分类页刚打开、数据尚未返回
- **THEN** 显示与最终版式同形的骨架占位，且骨架在 150ms 内不出现以避免闪烁

#### Scenario: 请求失败

- **WHEN** 列表或正文请求失败
- **THEN** 在内容原位显示一行说明文字与「重试」入口，不弹出对话框

### Requirement: 强调色只在三种状态出现

朱砂色 MUST 只用于阅读进度、当前章节、目录焦点三处，MUST NOT 用于装饰、导航选中态或图标默认色。

#### Scenario: 底部导航选中

- **WHEN** 用户切到某个底部 Tab
- **THEN** 选中项以墨色与字重区分，不使用朱砂

#### Scenario: 目录当前项

- **WHEN** 目录抽屉展开且当前章节在可视区
- **THEN** 该行出现朱砂胶囊或竖条，这是强调色在目录中的唯一出现位置
