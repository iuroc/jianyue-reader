# Proposal

## Why

需要一款能读「歌德电子书借阅机」图书与期刊的极简阅读器。现有同类客户端（青简）不在本工作区，
且不是 mjava 建树范式；服务端又不提供搜索与推荐（`keyword` 被静默忽略），发现内容只能靠分类浏览。
简阅要把「浏览 → 详情 → 阅读」这条链路做干净，把阅读界面做到退场，并在本地补上服务端缺失的搜索能力。

## What Changes

- 新建 iApp 工程 `com.jianyue.reader`（显示名「简阅」），源目录 `project/com.jianyue.reader/`。
- 5 个 `.iyu` 页面：`mian`（四 Tab 容器）、`bookdetail`、`magdetail`、`reader`、`search`。
- 17 个 `.mjava` 模块，分基础 / 通用 / 共享 / 数据 / 页面五层。
- 视觉采用「宣纸编辑式」：暖纸底、墨字、朱砂点缀，全 App 不用卡片，靠发丝线与留白分组。
- 图书与期刊各占一个一级 Tab，页内固定横向分类栏 + 三列书架网格 + 固定高度的「加载更多」。
- 阅读器一次只渲染一页（服务端页即页面），底栏常驻翻页按钮，正文按 30 页分段缓存。
- 目录为**递归树**抽屉（M3 模态抽屉），按最多 4 层预留，打开时自动展开祖先链并聚焦当前项。
- 本地搜索：首次搜索时后台并发建立全量索引（19 个分片，4 线程），支持断点续建与进度可见，
  索引完成前不允许搜索。
- **不做**：左右翻页手感、客户端分页重排、书签/笔记/划线、朗读、账号与同步、服务端搜索。

## Capabilities

### New Capabilities

- `design-system`: 设计 token（纸/夜双主题）、线稿图标规范、统一页头、按压反馈、加载/空/错误三态
- `navigation`: 底部四 Tab 与页面栈模型、页面之间的返回一致性、阅读页无页头的例外规则
- `book-browsing`: 图书分类栏、三列书架网格、分页追加与固定高度加载按钮
- `magazine-browsing`: 期刊分类、期刊封面网格、期刊详情与往期期次列表
- `reader`: 阅读会话——单页渲染、按钮翻页、分段缓存、外观设置、进度持久化与续读
- `table-of-contents`: 递归目录树、展开状态、按页号跳转、当前项自动聚焦
- `local-search`: 索引构建（分片并发、断点续建、进度可见）与本地子串匹配搜索

### Modified Capabilities

（无。这是新工程，不存在既有能力。）

## Impact

- **新增代码**：整份工程从零开始，无既有代码受影响。
- **外部依赖**：歌德借阅机 API（`gede.5read.com`，五个端点）；iApp ui-kit v0.1（vendor 一份进 `src/`）。
- **运行前提**：Android / iApp 5.0.1013，主开发机 API 34；网络可用。
- **数据落盘**：`filesDir/jianyue/` 下保存索引分片、索引状态、阅读进度与外观设置。
- **已知风险**：服务端分页尺寸与手机屏不完全对齐，页面可能需要页内滚动（设计已用「滚到底再翻页」兜住）；
  并发建索引的线程安全与限流阈值需上机实测。
